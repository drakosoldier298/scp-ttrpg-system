# **This is going to be long**
The entire System is supposed to be Modular, Meaning you can pick up whatever piece you want to and use it in another system, Or just remove parts without losing out on much or having to rework alot. 

The entire website is **EXAMPLES** And not a rule book. Its meant to show Would be Game masters how to create content for their wants and needs.

The examples can be used as is or changed. IT IS ENCOURAGED TO CHANGE SOME VALUES IF YOU USE THE ANOMALIES, This is to prevent metagaming, Which is when a player reads Game master Information and tries to use the knowledge despite their character having no knowledge of it.
